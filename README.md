# 📦 Supply Chain Management System (SCM)

গার্মেন্টস ও সাপ্লাই চেইন টিমের জন্য তৈরি করা একটি ফুল-ফিচার্ড ম্যানেজমেন্ট সফটওয়্যার।

---

## 🌟 মূল ফিচারসমূহ (Key Features)

1. **👥 Team & Member Management:**
   - প্রতি টিমে ৪-৬ জন মেম্বার এবং ১ জন Team Leader।
   - পুরো সিস্টেমের জন্য একজন **Boss (Admin)** যিনি ইউজার তৈরি, রোল নির্ধারণ ও কন্ট্রোল করতে পারেন।
   - পাসওয়ার্ড দিয়ে লগইন।

2. **👔 Buyer-wise Style Management:**
   - নিয়মিত বায়ার ভিত্তিক নতুন স্টাইল যোগ করা (Style No, Category, Season, Fabric, Color, Quantity, FOB Price, Status)।
   - মোট অর্ডারের মূল্য ($) অটো ক্যালকুলেশন।

3. **💬 Comments History & Updates (পুরানো কমেন্ট হিস্টোরি):**
   - স্টাইলের পুরানো সব কমেন্ট তারিখ ও সময়সহ সংরক্ষিত থাকবে (General, Update, Issue/Delay, Resolution)।
   - যেকোনো মেম্বার বা লিডার নতুন আপডেট পোস্ট করতে পারবে।

4. **📊 Reports & Printout (Management / Boss এর জন্য):**
   - ইচ্ছামতো ফিল্টার করে ছোট আকারে **Print View** (Direct Print to Paper/PDF)।
   - বায়ার, টিম এবং স্ট্যাটাস অনুযায়ী **Excel (.xlsx)** ও **PDF** রিপোর্ট জেনারেট।
   - রিপোর্ট একই ফোল্ডারে (`reports/`) সেভ হয়।
   - রিপোর্ট ডাউনলোড বা ওপেন করতে সিকিউরিটি পাসওয়ার্ড: **`2201`**।

## 🌐 অন্য কম্পিউটারের সাথে Sync করা (১০০% ফ্রি দিয়ে)

### অপশন ১: Render.com এ ফ্রি হোস্টিং (সবচেয়ে সহজ ও সেরা)
একটি কম্পিউটার থেকে সেভ দিলে সাথে সাথে অন্য সব কম্পিউটার ও মোবাইলে আপডেট দেখতে:
1. এই ফোল্ডারের কোড আপনার **GitHub** একাউন্টে একটি নতুন রিপোজিটরিতে আপলোড করুন।
2. **[Render.com](https://render.com)** এ গিয়ে ফ্রি একাউন্ট খুলুন।
3. **New +** > **Web Service** সিলেক্ট করে আপনার GitHub রিপোজিটরিটি কানেক্ট করুন।
4. Settings:
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
5. Render আপনাকে একটি ফ্রি লাইভ লিংক দেবে (যেমন: `https://my-scm.onrender.com`)। 
6. যেকোনো কম্পিউটার বা মোবাইল থেকে এই লিংকে ঢুকে কাজ করা যাবে এবং ডেটা সবার জন্য রিয়েল-টাইমে সিঙ্ক থাকবে!

### অপশন ২: একই অফিস / ওয়াইফাই নেটওয়ার্কে শেয়ার করা (Local Network)
ইন্টারনেট বা হোস্টিং ছাড়াও অফিসের ওয়াইফাইয়ের মাধ্যমে সব কম্পিউটার কানেক্ট করতে পারেন:
1. মূল কম্পিউটারটিতে `python app.py` বা `run.bat` চালু রাখুন।
2. কমান্ড প্রম্পটে `ipconfig` লিখে মূল কম্পিউটারের IP দেখুন (যেমন: `192.168.1.15`)।
3. অন্য কম্পিউটারগুলোর ব্রাউজারে লিখুন:
   ```
   http://192.168.1.15:5000
   ```
4. যেকোনো কম্পিউটার থেকে ডাটা সেভ দিলে সাথে সাথে ডাটাবেসে সেভ হবে এবং বাকি সবাই তা দেখতে পাবে!

## 💻 লোকাল মেশিনে রান করার নিয়ম (Quick Start)

### Windows এ ডাবল-ক্লিক করে চালানো:
- ফোল্ডারের ভেতরে থাকা `run.bat` ফাইলে ডাবল ক্লিক করুন।

### কমান্ড লাইন দিয়ে চালানো:
```bash
pip install -r requirements.txt
python app.py
```
ব্রাউজারে ওপেন করুন: `http://127.0.0.1:5000`
