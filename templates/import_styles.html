How it works
  • Style No and Buyer are required in every row.
  • A style with the same Style No + Buyer already in the system is updated — never duplicated, never deleted.
  • Blank cells keep the old value — they never erase data.
  • Buyers and Teams not found by name are created automatically.
  • A Remark column is saved as a comment (only when it differs from the latest one).
